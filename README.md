# AI Gaming Assistant (Java Swing)

Un'applicazione desktop leggera sviluppata in Java Swing che interagisce con l'API Gemini per rispondere a domande relative al mondo del gaming.

## Requisiti
- Java 8 o superiore
- Variabile d'ambiente `GEMINI_API_KEY` impostata sul sistema

## Avvio
Imposta la variabile d'ambiente prima di eseguire il codice:
```bash
set GEMINI_API_KEY=la_tua_api_key
java GameAssistantApp
